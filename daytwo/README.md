## Why a List of Dictionaries Is Useful for Storing Repeated Well Observations

A list of dictionaries is useful for storing sensor observations in an oil and gas company. A list allows us to store multiple observations, while each dictionary represents one sensor observation. Each dictionary contains information such as well ID, pressure, and temperature.

One important advantage is that a list allows repeated well IDs without losing any records. For example, WELL-07 can have three different pressure readings, and each reading can be stored as a separate dictionary. This helps us keep all the information collected from the wells.

We can also use dictionary keys to access specific information easily. This structure makes the data organised, readable, and easier to analyse.
